VoxelLauncher

不只是启动器！基于 Python + Tkinter 的 Minecraft 第三方启动器，
内置挖矿、宠物、AI 聊天、战斗系统，让启动器本身也变成游戏。

⬇ 立即下载 ⭐ GitHub 仓库

✨ 核心功能

启动游戏只是基础，娱乐才是本体

🚀

启动与下载

支持全版本下载、Fabric/Forge 加载器一键安装、Modrinth/CurseForge 模组下载、实例管理、高速下载与断点续传。

⛏️

挖矿系统

点击矿石挖矿，获得经验升级镐子，从木镐到钻石镐，不同镐子挖不同矿石，材料还能合成装备。

🐱

宠物系统

苦力怕和村民双宠物，在屏幕上走来走去，会说话、会互动，还能接入 AI 进行智能对话。

🤖

AI 聊天

支持豆包、Deepseek、Kimi 三个 API，自动检测服务商，宠物按角色设定回复，苦力怕和村民还能互相对话。

⚔️

战斗系统

独立战斗页面，夜晚刷僵尸和骷髅，武器从木剑到下界合金剑，击杀掉落物品，支持指令系统。

🔗

游戏联动

挖矿实时发送到游戏背包，击杀怪物时游戏附近同种怪物也死亡，启动器与游戏无缝联动。

🎣

钓鱼与养殖

钓鱼小游戏，等待鱼上钩把握时机拉杆，钓到各种鱼和宝藏；养殖系统养各种动物，贴图从游戏提取。

⚒️

合成系统

工作台合成物品，支持自定义皮肤，合成的物品可以用于升级装备和交易。

🚫

千万别点

设置页隐藏彩蛋，点了启动器就"疯了"，标题乱变、按钮骂人、窗口抖动，纯搞笑整蛊功能。

📸 界面预览

简洁现代的界面设计

🚀

启动页面

简洁的启动界面，支持自定义背景，一键启动游戏。

🎮

娱乐页面

挖矿、宠物、钓鱼、养殖，娱乐功能一应俱全。

⚔️

战斗页面

独立战斗系统，刷怪、武器、指令、战斗日志。
