核心功能

挖矿系统

在启动器里挖矿石，从煤矿到钻石、下界合金，挖到的矿石直接发送到游戏背包。支持多种镐子，越高级挖得越快。

战斗系统

夜晚会刷出僵尸、骷髅、蜘蛛。用木剑到下界合金剑击杀它们，掉落物进背包，同时游戏里附近的同种怪物也会被击杀。

钓鱼系统

真实的钓鱼手感，鱼的纹理从游戏资源提取。钓到的鱼直接发送到游戏，还有概率钓到宝藏和垃圾。

养殖系统

养鸡、养牛、养羊，动物贴图从游戏提取。收获鸡蛋、牛奶、羊毛，全部可以发送到游戏背包。

模组下载

内置 Modrinth 搜索，支持中文搜索、版本筛选、加载器筛选、模组图标显示。一键下载自动安装到实例。

游戏联动

通过轻量级 Bridge Mod 实现实时联动。启动器里获得的物品、击杀的怪物，游戏里同步生效。

娱乐玩法

启动器不只是用来启动游戏的。等待加载的时候、不想开游戏的时候，你可以在这里挖矿、打怪、钓鱼、养动物。获得的东西都能同步到游戏里，不白玩。

挖矿

点一下挖一下，越挖越深

就像在游戏里挖矿一样，点击矿石方块就能挖。从地表的煤矿、铁矿，到深层的钻石、下界合金，越深的矿石越难挖，但也越值钱。

  • 矿石会随时间慢慢刷新，挖完了等一会儿又有新的
  • 镐子有等级：木镐、石镐、铁镐、钻石镐、下界合金镐，越高级挖得越快
  • 挖到的矿石可以在熔炉里烧成锭，也可以直接发送到游戏背包
  • 挖矿会获得经验，等级高了能解锁更高级的镐子

战斗

夜晚会刷怪，拿起武器 defend yourself

游戏里有昼夜循环，到了晚上就会刷出僵尸、骷髅、蜘蛛这些敌对生物。你可以用剑击杀它们，获得掉落物。

  • 怪物有血量，不同怪物血量不同，僵尸20血，骷髅20血，蜘蛛16血
  • 武器有等级：木剑、石剑、铁剑、钻石剑、下界合金剑，伤害递增
  • 击杀怪物会掉落腐肉、骨头、线、蜘蛛眼等物品
  • 重点：在启动器里击杀某种怪物，游戏里你附近的同种怪物也会全部死亡！比如启动器里打死一只僵尸，游戏里你身边的僵尸都会死
  • 可以输入指令召唤铁傀儡、雪傀儡这些友好生物帮你打

钓鱼

抛竿、等鱼咬钩、收竿，真实手感

和游戏里一样的钓鱼机制：抛竿出去，等鱼漂下沉的时候收竿。鱼的纹理都是从游戏资源里提取的，看起来和游戏里一模一样。

  • 能钓到各种鱼：生鳕鱼、生鲑鱼、河豚、热带鱼
  • 有概率钓到宝藏：附魔书、命名牌、鞍、鹦鹉螺壳
  • 也有概率钓到垃圾：碗、钓鱼竿、皮革、水瓶
  • 钓到的鱼可以直接发送到游戏背包

养殖

养鸡养牛养羊，自给自足

可以养各种动物，定期收获产品。动物的贴图都是从游戏里提取的，和游戏里长得一样。

  • 养鸡：定期收获鸡蛋，鸡蛋可以孵出小鸡
  • 养牛：定期获得牛奶，用桶装
  • 养羊：定期剪羊毛，不同颜色的羊给不同颜色的羊毛
  • 养猪：定期获得猪肉
  • 收获的产品都可以发送到游戏背包

所有娱乐玩法获得的物品，都可以通过「发送到游戏」按钮同步到你正在运行的 Minecraft 存档里。不需要手动搬运，启动器帮你搞定。

游戏联动

什么是游戏联动？就是你在启动器里做的事，游戏里会真实发生。
启动器里挖到钻石，游戏背包里就多出一颗钻石；启动器里打死僵尸，游戏里你身边的僵尸也会一起死。
不需要切来切去，两个世界是连在一起的。

1
安装 Bridge Mod
在启动器设置里点「安装联动Mod」，会自动把一个很小的 Mod 装进你的游戏实例。这个 Mod 只负责和启动器通信，不影响游戏性能。
2
启动游戏
正常启动游戏，进入任意存档。启动器会自动检测到游戏运行，联动功能就激活了。
3
开始联动
在启动器里挖矿、打怪、钓鱼、养殖，获得的物品会自动发送到游戏背包，击杀的怪物会在游戏里同步死亡。

注意：联动功能需要游戏正在运行，并且安装了 Bridge Mod。只支持单机模式，不影响服务器。
